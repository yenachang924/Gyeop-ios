# 겹 (Gyeop)

> 아이폰을 맞대면, 우리는 겹친다.

**애플 디벨로퍼 아카데미 러너들을 위한 실사용 서비스**입니다. 아이폰을 맞대 만남을 인증하고, 여가 신호로 부담 없이 모이고, 포항에서의 9개월 동안 관계가 쌓이는 걸 눈으로 봅니다.

포트폴리오용 데모가 아닙니다. **지금 아카데미에 있는 러너들이 실제로 쓰는 것**이 이 앱의 유일한 성공 기준입니다.

## 왜 만들었나

아카데미는 9개월짜리 유한한 공동체입니다. 150명이 같은 건물에서 지내지만, 수료식에 돌아보면 진짜 친해진 사람은 10명 남짓 — 나머지 140명은 얼굴만 아는 채 흩어집니다.

원인은 성격이 아니라 구조라고 봤습니다.

1. **친해짐이 우연에 맡겨져 있다** — 팀 배정과 자리 운이 관계를 결정한다
2. **먼저 제안하는 사람이 비용을 다 낸다** — 거절 리스크 때문에 아무도 "놀자"를 못 꺼낸다
3. **9개월이 길다고 착각한다** — 미루다가 수료식에서 후회한다

**겹은 우연을 설계로 바꿉니다.** 앱 안에서 친해지는 게 아니라, 오프라인 만남의 발화·인증·기록만 맡습니다. 만남은 여전히 포항의 현실 공간에서 일어납니다.

### 피벗 스토리

이 프로젝트는 팀 CBL(Challenge Based Learning)에서 출발했습니다 — "아카데미에 있는 동안 다양한 관심사를 가진 사람들과 포항에서 여가를 보낼 수 있도록 돕자." 팀 리서치가 확인해준 것: 러너들 간 친밀감을 쌓고 싶은 니즈는 실재하고, 여가 모임은 작위적으로 시작되지 않는다는 것.

거기서 개인 프로젝트로 피벗하며 두 가지를 바꿨습니다. **문제 정의를 "여가 정보"에서 "관계의 구조"로 옮겼고**, 오프라인 임시방편(포스터·소모임 공지) 대신 **실제로 운영되는 온라인 서비스**로 만들었습니다. 팀의 리서치는 출발점으로, 구현과 운영은 온전히 개인의 몫으로.

## 무엇을 하나

### 🪪 정체성 카드
관심사와 여가 성향을 고르면 세상에 하나뿐인 카드가 생성됩니다. 같은 입력이면 언제나 같은 카드 — 카드가 곧 나입니다. (MeshGradient + Metal 셰이더 제너러티브 비주얼)

### 📱 카드 맞대기
처음 대화한 러너와 아이폰을 가까이 대면, 카드가 교환되고 **겹 1회**가 기록됩니다. 겹치는 관심사가 그 자리에서 하이라이트되어 다음 대화가 이어집니다. 와이파이가 없어도 됩니다 — 서버 없이 P2P로 동작합니다. (MultipeerConnectivity → NearbyInteraction UWB)

### 📡 여가 신호
"19시 보드게임, 라운지, 4명"을 켜면 관심사가 겹치는 러너에게 알림이 갑니다. 조인은 익명 카운트 — **아무도 거절당하지 않습니다.** 시간이 지나면 신호는 증발합니다. 참여자의 잠금화면에는 실시간 현황이 뜹니다. (APNs, Live Activity)

### 🧶 겹이 쌓인다
받은 카드, 만난 횟수, 수료까지 남은 날. 유한한 시간 안에서 관계가 쌓이는 걸 봅니다. 지표는 하나만 봅니다 — **오프라인에서 실제로 일어난 만남.**

## 기술

| 영역 | 선택 |
|---|---|
| UI | SwiftUI 100%, MeshGradient + Metal `layerEffect`, matchedGeometryEffect |
| P2P | MultipeerConnectivity (상태 머신), NearbyInteraction(UWB) 승격, CoreHaptics |
| 실시간 | Firestore 리스너, APNs 직접 호출(p8), ActivityKit Live Activity 푸시 갱신 |
| 데이터 | SwiftData (+서버 동기화 큐, idempotency), Keychain 직접 래핑 |
| 동시성 | Swift Concurrency, Swift 6 strict concurrency, AsyncStream 이벤트 처리 |
| 인증 | Sign in with Apple + 아카데미 이메일 검증, 계정 삭제 지원 |
| 품질 | Swift Testing, OSLog signpost, SPM 멀티모듈 |

각 선택의 이유는 [기술 문서](./gyeop-spec.md)와 [구현 체크리스트](./implementation-checklist.md)에 있습니다.
