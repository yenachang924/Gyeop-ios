# 겹(Gyeop) — 기능 고도화 로드맵 (피벗 v2)

> **2026-08 피벗 반영판.** 구버전(아카데미 러너 전용)의 로드맵을 대체한다. 대상: iOS 환경의 처음 만나는 사람들. 아카데미 러너는 사용자가 아니라 **피드백 그룹**이다.

앱 한 줄: 처음 만난 사람과 아이폰을 맞대 정체성 카드를 교환하고, 겹치는 관심사로 대화를 시작하게 하는 앱. **받는 쪽은 설치가 필요 없다(App Clip).**

**목표 선언:** 프로토타입 러너 피드백 라운드 → 5일 개발 → App Store 심사 제출 → 출시. 이후 **주간 릴리즈 트랙**으로 고도화를 계속한다. 파운데이션이 끝나도 이 트랙은 혼자 유지한다.

이 문서는 기능마다 **고도화 레벨(Lv.1 기본 → Lv.2 고도화 → Lv.3 완성형)**을 정의하고, 목표 지점(★)과 시점을 표시한 것이다.

## 2. 출시 트랙 — 연속 개발 모드 (데일리 구분 폐지)

날짜 박스(D1~D5) 대신 **우선순위 큐 + 항상 출시 가능한 최종본** 원칙으로 간다. 사이클 = 기능 덩어리 1개 구현 → 빌드·테스트 통과 → 커밋 → 최종본 갱신. **어느 시점에 잘라도 앱은 실행 가능해야 한다.** 빌드가 깨진 채로 다음 사이클 진입 금지.

| P | 덩어리 | 완료 기준 |
|---|---|---|
| **P0** | 걷는 뼈대 — SPM 멀티모듈 골격 + 온보딩 3단계 → 카드 생성 → 컬렉션 관통 + Telemetry 이식 | 시뮬레이터에서 끝까지 클릭 가능 |
| **P1** | 결정적 카드 완성 — MeshGradient, HSL 범위 고정(S70~80·L45~62), 이모지 시드 포함 | 같은 입력=같은 카드 단위 테스트 통과 |
| **P2** | MPC 교환 상태 머신 + 겹침 하이라이트 + 햅틱 | 실기기 2대 첫 교환 성공 |
| **P3** | App Clip 타깃 + 무계정 플로우 + SKOverlay 전환 + 데이터 마이그레이션 | 클립→풀앱 이전 확인 · 35MB 이내 |
| **P4** | SwiftData 영속화 + 겹 기록 규칙(24h 중복 집계) | 재실행 후 데이터 유지 |
| **P5** | SiwA + Keychain 래핑 + **계정 삭제** | 심사 요건 충족 |
| **P6** | 엣지 처리(교환 실패·중복·권한 거부) + 심사 대비물(시연 영상 2대·스크린샷·처리방침·App Clip 경험 등록·데모 계정) + **심사 제출** | App Store 제출 완료 |

고정점은 두 개만 남긴다:
- **심사 제출 데드라인** (기존 D5 시점 유지) — 큐가 밀리면 아래 P를 지우지, 데드라인을 늦추지 않는다. 컷 순서: P3 클립 내 교환 축소(카드 수신만) → P2 햅틱 → P1 셰이더 질감
- **제출 후 버퍼** — 심사 대응 전담 2일(새 기능 금지) → 출시 확정 + 첫 현장 테스트(실제 첫 만남이 일어나는 자리 1곳에서 QR 시연)

병렬 트랙: **러너 프로토타입 피드백 라운드는 개발과 동시에** 진행하고, 결과는 다음 사이클에 반영한다 (개발을 멈추고 기다리지 않는다).

**완료 정의: 출시 라이브 + 현장 테스트 1회 + 교환 20건 + 클립→풀앱 전환 관측 시작**

크리티컬 패스(즉시): Apple Developer Program 등록 확인 / App Clip용 어소시에이티드 도메인·웹 서버 준비 / 실기기 2대

## 4. 피드백 요청 지점

**러너 피드백 라운드(D0)에서:** README의 검증 질문 5개 — 특히 설치 제안 타이밍과 15초 카드 생성.

**멘토님께:**
1. **App Clip 코어 판단** — 클립 안에서 교환까지 넣는 것(★) vs 클립은 카드 수신만 하고 교환은 풀앱 전용으로 줄이는 것, 어느 쪽을 권하시는지
2. **★출시 컷** — D5 제출 기준으로 ③Lv2(클립 내 교환)까지가 적정한지
3. **심사 리스크** — App Clip 심사(디폴트 경험·35MB·무계정)에서 놓친 리젝 포인트가 있는지
4. **매일 저녁 10분 밀림 판정 체크인** 가능 여부, 파운데이션 이후 멘토링을 이어받을 방법
