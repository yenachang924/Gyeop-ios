### 미결 항목 — 소유자 선택 대기 (임의 진행 금지)

1. **1/3 색 표현**: 과한 구획 → 수채화 연속 스펙트럼·무지개 모티브, blur 강화, 화면보호기 느낌 + variation. 2~3안 시각 비교 필요.
2. **2/3 위치·리디자인**: 상단 → 중앙 이동 여부, 4택1 격자 → "면적 선택" 방식 전환 여부 (레퍼런스 조사 포함).
3. **liquid glass 적용 범위**: iOS 26 Liquid Glass 머티리얼을 어디까지 (1/3·2/3 우선 언급됨).
4. **겹침 0개일 때 카드 하단 알약에 무엇을 보여줄지**.
5. **"뿅" 사운드**: 겹 성립 시 AirDrop류 사운드 추가 여부 — 현재 앱에 사운드 레이어 없음(신규 영역).
6. **첫 화면(웰컴)**: 소유자가 Figma로 직접 (색상 팔레트 포함). 코드 세션은 손대지 않는다.
7. **앱 아이콘**: POSTECH 라운지 색상 기반으로 재작업 예정 — 라운지 색상 값 확보 필요.
