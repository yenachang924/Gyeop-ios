# figma/ — Figma 제작용 화면 세트

겹(Gyeop) v0.1의 9개 화면. **iPhone 15 Pro 규격(393×852pt)**의 SVG로, Figma에 드래그하면 편집 가능한 벡터·텍스트 레이어로 열린다.

## Figma로 가져가는 법 (2가지)

**방법 A — SVG 임포트 (권장, 완전 편집 가능)**
1. Figma에서 새 파일 → 이 폴더의 SVG 9개를 캔버스에 드래그
2. 각 SVG가 프레임으로 들어옴 → 프레임 이름을 파일명대로 정리
3. 폰트는 시스템 매핑됨 — **SF Pro** (Apple 공식 무료) + **Pretendard** 설치 후 텍스트 레이어에 일괄 적용 권장
4. 프로토타입 탭에서 버튼 → 다음 화면으로 커넥션 연결 (플로우 순서 = 파일 번호 순서)

**방법 B — html.to.design 플러그인 (전체 페이지 통째로)**
1. Figma 플러그인 `html.to.design` 실행
2. 레포의 `gyeop-prototype.html` 파일 내용을 붙여넣기 → 페이지 전체가 레이어로 변환

## 플로우 (프로토타입 커넥션 순서)

```
01 App Clip 수신 → 02 관심사(1/3) → 03 성향(2/3) → 04 한 줄(3/3)
→ 05 내 카드 → 06 맞대기 → 07 겹 결과 → 08 보관·설치 제안 → 09 컬렉션
```

설치 제안(08)이 교환(06~07) **뒤에** 오는 순서가 이 플로우의 핵심 주장이다. 순서를 바꾸지 말 것.

## 디자인 토큰 (Figma 스타일로 등록할 것)

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg/base` | `#F2F2F7` | iOS 화면 배경 |
| `surface` | `#FFFFFF` | 카드·입력·배너 |
| `ink/primary` | `#111114` | 제목·본문 |
| `ink/secondary` | `#6C6C72` | 서브카피 |
| `ink/tertiary` | `#B4B4BC` | 플레이스홀더·dim |
| `line` | `#E3E3E8` | 테두리 |
| `action` | `#17171A` | 프라이머리 버튼 |
| `overlap/bg · line · ink` | `#E1E7CC · #C6D19E · #45521F` | 겹침 하이라이트 (브랜드 올리브) |
| `clip/bg · ink` | `#E8EEFB · #3A6DD8` | App Clip 배지 |
| `grad/me` | `#2E4E9E → #3F9FC0 → #7FC98F` | 내 카드 (목업 고정값) |
| `grad/you` | `#E8A54B → #E06A5A → #8F5AB0` | 상대 카드 (목업 고정값) |

타입 스케일: 제목 26–28/800 · 섹션 24/800 · 버튼 16/700 · 본문 13 · 캡션 11–12. 코너: 카드 18–20 · 버튼 14 · 입력 12 · 칩 높이의 ½.

**주의 — 카드 그라디언트는 목업용 고정값이다.** 실구현에서는 선택값 해시로 결정적 생성된다(MeshGradient). Figma에서는 "같은 입력=같은 카드"를 주석으로 명시할 것.

## iOS 최적화 체크리스트 (Figma 작업 시 유지할 것)

- 세이프 에어리어: 상단 59pt(Dynamic Island) · 하단 34pt(홈 인디케이터) 침범 금지 — 목업의 버튼 위치가 기준
- 터치 타깃 최소 44×44pt — 칩(38pt)은 히트 영역을 44pt로 확장하는 주석 달기
- 텍스트는 SF Pro/Pretendard, Dynamic Type 대응 전제 (고정 px 아님)
- 버튼은 화면 하단 고정(엄지 존), 뒤로 가기는 시스템 스와이프에 위임
