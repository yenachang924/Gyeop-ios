# 카드 뒷면 분리 글라스 에셋 설계

## 목표

카드 뒷면을 소유자 레퍼런스의 정보 위계에 맞춘다. MBTI와 관심사 이름은 카드 세로 중앙 왼쪽에 그대로 두고, 관심사를 대표하는 큰 이모지 에셋은 카드 우측 상단에 올린다. 배경은 현재 오라를 유지하되 Apple 배경화면처럼 반투명 유리 레이어가 겹친다.

## 카드 정보 배치

`CardBackView`의 MBTI 위치와 크기는 변경하지 않는다. 관심사 이름은 MBTI 아래에서 세로로 읽히며, 각 이름은 작은 Liquid Glass 캡슐로 분리한다. 칩 사이에는 `DS.Spacing.xs`를 유지한다.

대표 이모지는 관심사 이름 안에 넣지 않는다. 최대 다섯 개를 카드 우측 상단에 원형 Liquid Glass 버블로 쌓는다. 첫 버블은 가장 위·오른쪽에, 이후 버블은 아래·왼쪽으로 조금씩 이동하여 모두의 테두리와 이모지가 보이게 한다. 이모지는 현재 관심사 에셋보다 크게 그리지만, 기존 `DS.Typo` 타입만 사용한다.

## 겹친 Liquid Glass 배경

`CardBackView`의 기존 MeshGradient 위에 정적인 반투명 material 타원 두 장을 추가한다. 각 타원은 다른 크기와 앵커를 사용해 겹치며, 카드의 색을 비치게 한다. 라이트·다크에서 시스템 material이 표면을 결정한다. 반복 애니메이션, 새 색상, 래스터 이미지, 텍스처는 추가하지 않는다.

## 구조

CardKit에 `CardInterestAssets` 전용 하위 뷰를 둔다. 이는 `card.interests`와 기존 `InterestSymbol`을 받아 우측 상단의 버블 묶음만 렌더한다. 관심사 라벨 뷰는 좌측 세로 칩만 책임진다. 카드 배경 레이어도 CardKit의 전용 하위 뷰로 둬 앞면과 다른 시드 계약에 영향을 주지 않는다.

## 검증

- 최대 다섯 관심사의 버블이 모두 결정적 순서로 보이는지 단위 테스트로 확인한다.
- iPhone 17 Pro 라이트·다크 및 Dynamic Type 화면에서 MBTI·좌측 칩·우측 이모지 묶음이 카드 밖으로 나가지 않는지 UI 스크린샷으로 확인한다.
- 카드 정지 상태에는 추가 반복 애니메이션이 없는지 코드 검토와 기존 전체 UI 흐름으로 확인한다.
