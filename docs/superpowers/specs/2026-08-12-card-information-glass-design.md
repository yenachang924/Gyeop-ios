# 카드 정보 포스터·글라스 크롬 설계

## 목표

소유자가 제공한 홈 카드 레퍼런스의 정보 형식을 SwiftUI 네이티브 카드에 정확히 반영한다. 카드 앞면은 현재의 오라 카드 구조를 유지하고, 뒷면만 MBTI와 요즘의 나를 이루는 관심사 에셋이 읽기 쉬운 세로 포스터가 되게 한다. 동시에 홈의 지속 렌더링을 줄인다.

## 범위

### 카드 뒷면

`CardBackView`는 카드의 좌상단을 시작점으로 한다. MBTI 유리 글자를 먼저 두고, 그 아래에 최대 다섯 개의 작은 세로 관심사 칩을 둔다. 각 칩은 대표 이모지와 원래의 관심사 이름을 함께 표시한다. 글자 크기, 여백, 카드 비율은 이미 승인된 DesignSystem 토큰을 사용하며, 긴 관심사도 말줄임표 대신 칩 자체의 고유 크기로 보존한다.

관심사 이모지 매핑은 CardKit이 소유한다. App의 `EmojiCatalog`는 번들 리소스를 읽으므로 CardKit이 의존하지 않는다. 새 순수 `InterestSymbol` API가 알려진 관심사 이름에 대한 고정 이모지를 반환하고, 알 수 없는 이름에는 `✨`를 반환한다. 따라서 받은 카드도 어느 화면에서나 같은 에셋으로 보인다.

### 온보딩 MBTI

`MBTIStepView`의 질문 제목과 CTA는 바꾸지 않는다. 네 개의 세 컬럼 선택 행만 화면 중앙의 공통 최대 폭으로 묶는다. 기존의 선택 틴트, letterPop, bloom, 건너뛰기 동작은 변경하지 않는다.

### 홈 설정 버튼

컬렉션 헤더의 설정 버튼은 44pt 원형을 유지한다. iOS 26에서는 `glassEffect(.regular, in: Circle())`로 확실한 Liquid Glass 표면을 쓰고, 이전 OS에서는 system material과 원형 테두리를 사용한다. 아이콘은 기존 `gearshape`, 색은 무채 시스템 primary다.

### 성능

홈의 `ShimmerFrame`은 반복 애니메이션을 제거한 정지 광택으로 교체한다. 또한 `CardFlipView`는 멈춰 있을 때 보이지 않는 면을 만들지 않는다. 탭 플립 중에만 양쪽 면을 한시적으로 렌더해 3D 플립을 유지하고, 완료 뒤 이전 면을 제거한다. Reduce Motion은 기존처럼 즉시 교체한다.

## 경계와 오류 처리

CardKit의 관심사 심볼은 순수 값 변환이며 오류를 던지지 않는다. 화면 상태 및 저장 경로는 바꾸지 않는다. 카드 비주얼, 컬러 생성, 보안, WelcomeView는 범위 밖이다.

## 테스트와 검증

- CardKit 단위 테스트는 알려진 관심사의 결정적 이모지와 미등록 관심사의 폴백을 검증한다.
- UI 테스트는 카드 뒷면의 MBTI·관심사 접근성 라벨, 중앙 MBTI 선택 행, 원형 설정 버튼을 확인한다.
- iPhone 17 Pro 라이트·다크 전체 UI 흐름 스크린샷을 xcresult attachment에서 추출해 레퍼런스와 비교한다.
- 커밋 전 앱 빌드와 패키지 테스트를 모두 직접 실행한다.
