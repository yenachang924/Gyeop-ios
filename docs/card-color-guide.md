# 카드 색 읽는 법 — 공식 문서 (F21·F25·F56·F61·F72)

애플 건강 앱이 지표를 공식 문서로 알려주듯, 겹은 카드 색이 무엇을 담는지 앱의 공식
문서로 알려준다. 이 문서가 단일 진실 원천이고, 인앱 화면(설정 > 카드 색 읽는 법,
`CardColorGuideView`)은 이 내용을 그대로 보여준다.

## 카드는 무엇인가

카드의 색은 **나를 이루는 선택들을 종합적으로 담아낸 것**이다. 고른 관심사, MBTI,
닉네임, 이모지가 모두 시드로 섞여 세상에 하나뿐인 **색의 흐름**이 되고,
같은 입력이면 언제나 같은 카드가 된다.

특정 색이 특정 취미나 유형을 뜻하지는 않는다 — 색은 그 사람 전체의 인상이다.
무엇 하나를 바꾸면 카드 전체가 다르게 물든다.

## 규칙의 변천 (기록)

- 초기: 25개 제어점 전부 무작위 → 실기기에서 무지개 노이즈 (기각)
- F21: 성향 기반 웜/쿨 유사색 7색 → "너무 이분법적" (기각)
- F24: 퍼짐·밝기만 성향에 연동 → "결정으로 하라고 한 적 없다" (기각)
- F25: 7색 상한만 유지, 색상·배치 전부 무작위. 은은함은 채도(70~80%)·명도(45~62%)의
  규율과 흰 텍스트 4.5:1 대비 보정이 만든다
- F56 (2026-08-12 소유자 오라 레퍼런스): 딥 톤을 오라 파스텔로 반전 —
  대역을 **채도 25~45% · 명도 82~96%**(밝고 뽀얀 고명도 저채도)로. 카드 위 텍스트도
  흰색 → **잉크**(#33283A 고정), 대비 보정은 잉크 기준 4.5:1(명도를 올리고, 모자라면
  채도를 뺀다. 천장 0.97).
- **F61 (최종, 같은 날 레퍼런스 2차): 색 종류 축소 + 무작위 배치 은퇴.**
  한 카드는 **4색 앵커**가 네 코너에 앉고 나머지 제어점은 이중선형 보간으로 그 사이를
  흐른다. 앵커 hue는 기준 hue에서 이웃 간격(0.08~0.15)으로만 스윕 — 레퍼런스처럼
  인접 색(파랑→보라→분홍→주황)이 큰 면으로 부드럽게 이어진다.
- **F72: 리본 배경화면식 카드별 변주.** 4색 앵커와 오라 대역은 유지하고, 시드에서 정한
  서로 다른 앵커를 쓰는 두 개의 넓은 대각 리본을 코너 흐름에 겹친다. 리본의 방향·폭·중심선·
  앵커 출처가 카드마다 달라져도, 줄무늬나 노이즈 없이 큰 색 면이 교차한다.

## 구현 참조

- `CardVisual(seed:)` — 4색 앵커(인접 hue 스윕) + 코너 이중선형 보간 위에
  두 넓은 대각 리본을 결정적으로 혼합한다. 오라 대역과 잉크 대비 보정은 그대로 유지하며,
  잉크는 `CardVisual.inkColor`.
- 시드 규칙 `CardSeed.hash` — 정렬된 관심사 + MBTI 코드(건너뛰면 빈 값) + 닉네임 + 이모지.
- 카드 뒷면(`CardBackView`)은 같은 오라 위에 유리(Material)를 덮는다 — 뒤집어도
  같은 카드라는 감각이 hue로 이어진다 (F54).
- 인앱 노출: `SettingsView` → "카드 색 읽는 법" (navigation-map §3).
