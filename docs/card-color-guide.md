# 카드 색 읽는 법 — 공식 문서 (F21·F25·F56)

애플 건강 앱이 지표를 공식 문서로 알려주듯, 겹은 카드 색이 무엇을 담는지 앱의 공식
문서로 알려준다. 이 문서가 단일 진실 원천이고, 인앱 화면(설정 > 카드 색 읽는 법,
`CardColorGuideView`)은 이 내용을 그대로 보여준다.

## 카드는 무엇인가

카드의 색은 **나를 이루는 선택들을 종합적으로 담아낸 것**이다. 고른 관심사, MBTI,
닉네임, 이모지가 모두 시드로 섞여 세상에 하나뿐인 **일곱 빛깔**이 되고,
같은 입력이면 언제나 같은 카드가 된다.

특정 색이 특정 취미나 유형을 뜻하지는 않는다 — 색은 그 사람 전체의 인상이다.
무엇 하나를 바꾸면 카드 전체가 다르게 물든다.

## 규칙의 변천 (기록)

- 초기: 25개 제어점 전부 무작위 → 실기기에서 무지개 노이즈 (기각)
- F21: 성향 기반 웜/쿨 유사색 7색 → "너무 이분법적" (기각)
- F24: 퍼짐·밝기만 성향에 연동 → "결정으로 하라고 한 적 없다" (기각)
- F25: 7색 상한만 유지, 색상·배치 전부 무작위. 은은함은 채도(70~80%)·명도(45~62%)의
  규율과 흰 텍스트 4.5:1 대비 보정이 만든다
- **F56 (최종, 2026-08-12 소유자 오라 레퍼런스): 딥 톤을 오라 파스텔로 반전.**
  7색 상한·색상 무작위·25점 무작위는 승계하되, 대역을 **채도 25~45% · 명도 82~96%**
  (밝고 뽀얀 고명도 저채도)로 뒤집었다. 카드 위 텍스트도 흰색 → **잉크**(#33283A 고정)로
  바뀌었고, 대비 보정은 잉크 기준 4.5:1 — 부족하면 명도를 올리고(천장 0.97),
  그래도 모자라면 채도를 뺀다. 두 축 모두 "더 뽀얘지는" 방향이라 오라의 결이 유지된다.

## 구현 참조

- `CardVisual(seed:)` — 7색 팔레트(각각 색상환 전체에서 무작위) + 25점 무작위 배치,
  오라 대역과 잉크 대비 보정. 잉크는 `CardVisual.inkColor`.
- 시드 규칙 `CardSeed.hash` — 정렬된 관심사 + MBTI 코드(건너뛰면 빈 값) + 닉네임 + 이모지.
- 카드 뒷면(`CardBackView`)은 같은 오라 위에 유리(Material)를 덮는다 — 뒤집어도
  같은 카드라는 감각이 hue로 이어진다 (F54).
- 인앱 노출: `SettingsView` → "카드 색 읽는 법" (navigation-map §3).
