# 카드 색 읽는 법 — 공식 규칙 (F21·F24)

애플 건강 앱이 지표를 공식 문서로 알려주듯, 겹은 카드 색이 무엇을 담는지 앱의 공식
규칙으로 알려준다. 이 문서가 단일 진실 원천이고, 인앱 화면(설정 > 카드 색 읽는 법,
`CardColorGuideView`)은 이 내용을 그대로 보여준다.

## 카드는 무엇인가

카드의 색은 **한 사람의 취미와 성향을 종합적으로 담아낸 것**이다. 고른 관심사,
이름, 한 줄, 이모지가 모두 시드로 섞여 세상에 하나뿐인 색 조합이 되고,
같은 입력이면 언제나 같은 카드가 된다. 특정 색이 특정 취미를 뜻하지는 않는다 —
색은 그 사람 전체의 인상이다.

## 규칙 (F24 — 이분법 폐기 절충안)

한 장의 카드는 **7가지 색**으로만 물든다. 기준 색은 색상환 전체에서 나와
카드마다 형형색색하되, 성향은 색의 **결**에 은은하게 배어든다:

| 신호 | 카드에 드러나는 방식 |
|---|---|
| **활발** (energy = active) | 7색이 넓게 퍼진다 — 형형색색, 다채로운 결 |
| **잔잔** (energy = calm) | 7색이 좁게 모인다 — 차분하고 단정한 결 |
| **실외** (venue = outdoor) | 밝은 명도대 — 볕이 든 듯 맑다 |
| **실내** (venue = indoor) | 깊은 명도대 — 조명이 낮은 듯 아늑하다 |

~~F21의 웜/쿨 이분법(활발=레드~골드, 잔잔=틸~인디고)~~ 은 "너무 이분법적"이라는
소유자 피드백으로 폐기 — 다양한 취미가 형형색색으로 드러나는 것이 우선이다.

## 구현 참조

- `CardVisual(seed:style:)` — 기준 색상은 시드가 색상환 전체에서,
  energy → 퍼짐(`hueSpreadActive` 0.36 / `hueSpreadCalm` 0.24),
  venue → 명도 대역(실외 0.53~0.62 / 실내 0.45~0.54), 7색 대각 흐름 배치.
- 흰 텍스트 4.5:1 대비 보정은 팔레트 색 단위로 유지 (R2 계약 승계).
- 인앱 노출: `SettingsView` → "카드 색 읽는 법" (navigation-map §3).
