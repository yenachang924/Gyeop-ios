# 카드 색 읽는 법 — 공식 규칙 (F21)

애플 건강 앱이 "심박변이도가 무엇인가요"를 공식 문서로 알려주듯, 겹은 카드 색이
무엇을 말하는지 앱의 공식 규칙으로 알려준다. 이 문서가 단일 진실 원천이고,
인앱 화면(설정 > 카드 색 읽는 법, `CardColorGuideView`)은 이 내용을 그대로 보여준다.

## 규칙

한 장의 카드는 **7가지 색**으로만 물든다. 색의 큰 방향은 성향이 정하고,
그 안의 미묘한 차이는 이름·한 줄·이모지·관심사가 정한다. 같은 입력이면 언제나 같은 카드다.

| 신호 | 카드에 드러나는 방식 |
|---|---|
| **활발** (energy = active) | 웜 톤 — 레드에서 골드 사이의 온기 |
| **잔잔** (energy = calm) | 쿨 톤 — 틸에서 인디고 사이의 고요 |
| **실외** (venue = outdoor) | 밝은 명도대 — 볕이 든 듯 맑다 |
| **실내** (venue = indoor) | 깊은 명도대 — 조명이 낮은 듯 아늑하다 |
| 이름·한 줄·이모지·관심사 | 7색이 색상환 어디서 시작하고 어떻게 흐르는지(시드) |

읽는 예: **따뜻하고 밝은 카드** = 활발 · 실외 (러닝·서핑의 결) /
**차갑고 깊은 카드** = 잔잔 · 실내 (보드게임·독서의 결).

## 구현 참조

- `CardVisual(seed:style:)` — 7색 유사색 팔레트(`paletteCount`·`hueSpread`),
  energy → 기준 색상 대역(웜 0.96~1.10 / 쿨 0.50~0.68),
  venue → 명도 대역(실외 0.53~0.62 / 실내 0.45~0.54), 대각 흐름 배치.
- 흰 텍스트 4.5:1 대비 보정은 팔레트 색 단위로 유지 (R2 계약 승계).
- 인앱 노출: `SettingsView` → "카드 색 읽는 법" (navigation-map §3).
