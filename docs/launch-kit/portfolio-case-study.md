# 겹(Gyeop) | 아이폰을 맞대면, 만남이 쌓입니다

## 프로젝트 개요

겹은 처음 만난 두 사람이 아이폰을 가까이 대 카드와 관심사를 교환하고, 실제로 만난 순간을 기록하는 iOS 앱이다. 앱 안에서 오래 머무르게 하는 대신, 오프라인 대화가 시작될 수 있는 가장 작은 계기만 설계했다.

| 항목 | 내용 |
|---|---|
| 플랫폼 | iOS, SwiftUI |
| 배포 | TestFlight `1.0 (3)` |
| 핵심 경험 | 정체성 카드 생성, 1:1 근접 카드 교환, 받은 카드 보관 |
| 역할 | 제품 정의, UX, UI, iOS 구현, 테스트 및 TestFlight 배포 |
| 검증 | iPhone 17 Pro 빌드, Swift Testing 72개, XCUITest 전체 흐름 7개 |

## 문제

처음 만난 사람과 친해지고 싶어도 먼저 말을 거는 쪽만 어색함과 거절의 위험을 감당한다. 겹은 "누가 먼저 제안했는가"보다 "이미 가까이 있는 두 사람이 대화를 시작할 수 있는가"에 집중했다.

## 해결 방식

### 1. 나를 설명하는 카드

관심사, MBTI, 한 줄 소개, 이모지를 입력하면 시드 기반의 카드가 생성된다. 카드 뒷면에서는 MBTI와 관심사를 먼저 보여줘, 처음 만난 사람도 대화 소재를 빠르게 찾을 수 있다.

### 2. 가까운 두 사람만의 교환

카드 교환은 공개 프로필, 검색, 피드 없이 1:1 근접 상호작용으로 시작한다. 실기기에서는 MultipeerConnectivity 기반 교환을 사용하고, 시뮬레이터와 기기 한 대에서는 Mock 경로로 같은 전체 경험을 확인할 수 있게 했다.

### 3. 쌓이는 기록, 경쟁하지 않는 관계

교환한 카드는 컬렉션에 남는다. 받은 카드는 길게 눌러 삭제할 수 있고, 계정 삭제도 앱 안에서 바로 가능하다. 랭킹이나 공개 관계 그래프 대신, 사용자가 직접 만난 기록만 남긴다.

## 디자인과 기술의 핵심 결정

| 과제 | 결정 | 이유 |
|---|---|---|
| 카드의 일관성 | 입력값을 해시 시드로 변환 | 프리뷰, 저장 카드, 받은 카드가 같은 모습으로 읽히게 함 |
| 카드 배경 | 4색 앵커와 5×5 MeshGradient | 카드마다 변주가 있으면서도 하나의 브랜드 언어 유지 |
| 가독성 | 잉크 대비 4.5:1 자동 보정 | 파스텔 배경에서도 이름과 MBTI를 읽을 수 있게 함 |
| 성능 | 정지 시 한 면만 렌더 | 양면 Material 합성과 반복 쉬머로 생긴 느려짐 제거 |
| 접근성 | Dynamic Type와 접근성 라벨, UI 전체 흐름 테스트 | 예쁜 고정 화면이 아니라 실제 사용 흐름을 검증 |

## 결과와 배운 점

카드 디자인은 여러 번 바뀌었다. 특히 카드 위에 올린 별도 유리 오브젝트는 스크린샷에서는 눈에 띄었지만, 실제 사용에서는 카드의 표면을 분절시키고 렌더 비용도 키웠다. 이를 제거하고 앞·뒤가 같은 시드 기반 배경을 공유하도록 바꾸면서, 시각적 정체성과 성능을 함께 회복했다.

이 프로젝트에서 얻은 가장 큰 기준은 다음이다.

> 기능의 완성은 화면 하나가 아니라, 실제 사용 흐름과 배포 가능한 품질까지 확인했을 때 성립한다.
