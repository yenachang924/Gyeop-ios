# 겹 (Gyeop)

> 아이폰을 맞대면, 우리는 겹친다.

**처음 만난 사람과 아이폰을 맞대 정체성 카드를 교환하는 iOS 앱**입니다. 명함처럼 형식적이지 않고, 연락처 교환처럼 무겁지 않게 — 서로의 관심사가 겹치는 지점이 그 자리에서 하이라이트되어, 다음 대화가 시작됩니다.

**받는 사람은 앱이 없어도 됩니다.** App Clip이 그 자리에서 열립니다.

## 왜 만들었나

처음 만나는 자리의 어색함은 성격 문제가 아니라 도구 문제라고 봤습니다.

1. **자기소개는 매번 같은 말을 반복하게 한다** — 그리고 헤어지면 아무도 기억하지 못한다
2. **연락처 교환은 무겁다** — "번호 주세요"가 성립하는 순간 관계에 부담이 실린다
3. **공통점 찾기에 대화의 대부분을 쓴다** — 정작 겹치는 지점은 헤어진 뒤에야 발견된다

겹은 이 마찰을 **15초**로 줄입니다. 아이폰을 맞대면 카드가 교환되고, 겹치는 관심사가 바로 하이라이트됩니다. 앱은 만남의 시작만 맡고, 대화는 사람이 합니다.

### 피벗 스토리

**1차 피벗 — 팀에서 개인으로.** 팀 CBL 리서치("여가 정보 제공")에서 출발해, 문제 정의를 "관계의 구조"로 옮기고 실제 운영되는 서비스로 만들기로 했습니다.

**2차 피벗 — 아카데미에서 세상으로 (2026-08, 멘토 피드백 반영).** 처음엔 아카데미 러너 전용 커뮤니티 앱이었습니다. 멘토 피드백이 구조적 리스크를 짚어줬습니다:

- 아카데미 종속 = **개인정보·보안 전제**가 무겁고, **멘토와 운영 환경이 매 기수 바뀌어** 서비스의 영속성을 보장할 수 없다
- 러너들에게 시연하는 순간 **아이디어가 그들의 것이 될 수 있다** — 그들이 직접 만들면 되는 구조
- 나는 아카데미 밖에 있다 — 그 생태계에 대한 이해도는 러너들이 더 높다

그래서 대상을 뒤집었습니다. **아카데미 러너는 이 앱의 사용자가 아니라, 가장 가까운 피드백 그룹입니다.** 앱 자체는 iOS 환경의 모든 "처음 만나는 사람들"을 향합니다 — 모임, 행사, 스터디, 네트워킹, 첫 만남 어디든.

## 무엇을 하나

### 🪪 정체성 카드
관심사와 여가 성향을 고르면 세상에 하나뿐인 카드가 생성됩니다. 같은 입력이면 언제나 같은 카드 — 카드가 곧 나입니다. (MeshGradient + Metal 셰이더 제너러티브 비주얼)

### 📱 카드 맞대기
처음 만난 사람과 아이폰을 가까이 대면 카드가 교환되고 **겹 1회**가 기록됩니다. 겹치는 관심사가 그 자리에서 하이라이트되어 다음 대화가 이어집니다. 와이파이가 없어도 됩니다 — 서버 없이 P2P로 동작합니다. (MultipeerConnectivity → NearbyInteraction UWB)

### 📎 App Clip — 받는 사람의 비용은 0
상대에게 앱이 없어도 교환이 성립합니다. QR/링크로 App Clip이 즉시 열리고, 15초 안에 카드를 만들어 맞댈 수 있습니다. **설치 제안은 교환이 끝난 뒤에만** — 가치를 먼저 경험하게 하고, 보관하고 싶어질 때 전체 앱을 권합니다.

### 🧶 겹이 쌓인다
받은 카드, 만난 사람, 겹친 관심사. 스쳐 지나갈 뻔한 만남이 기록으로 남습니다. 지표는 하나만 봅니다 — **오프라인에서 실제로 일어난 만남.**

## 하지 않는 것

풀 채팅 (메신저를 이길 이유가 없음) · 팔로우/친구 신청 (거절이 성립하는 순간 앱이 부담이 됨) · 피드형 소셜 (체류시간은 적) · 프로필 열람 (맞대지 않은 사람의 카드는 볼 수 없음 — 만남 없이는 아무 일도 일어나지 않는다)

## 기술

| 영역 | 선택 |
|---|---|
| UI | SwiftUI 100%, MeshGradient + Metal `layerEffect`, matchedGeometryEffect |
| P2P | MultipeerConnectivity (상태 머신), NearbyInteraction(UWB) 승격, CoreHaptics |
| 진입 | **App Clip** (35MB 이하 타깃, QR·링크·NFC 인보케이션), 설치 전환 플로우 |
| 데이터 | SwiftData (+서버 동기화 큐, idempotency), Keychain 직접 래핑 |
| 동시성 | Swift Concurrency, Swift 6 strict concurrency, AsyncStream 이벤트 처리 |
| 인증 | Sign in with Apple, 계정 삭제 지원 (App Clip은 무계정 시작) |
| 품질 | Swift Testing, OSLog signpost, SPM 멀티모듈 |

각 선택의 이유는 [기술 문서](./gyeop-spec.md)와 [구현 체크리스트](./implementation-checklist.md)에 있습니다.

## 검증 계획

프로토타입 → 아카데미 러너 피드백 → 개발 착수. 러너들은 방금 사용자 경험 챌린지를 끝낸, 가장 가까운 UX 리뷰어 그룹입니다. 프로토타입 단계에서 검증할 질문:

1. App Clip 설치 제안 타이밍(교환 후)이 자연스러운가, 이른가?
2. 카드 만들기가 정말 15초 안에 끝나는가?
3. 겹침 하이라이트가 실제 대화로 이어지는가?
4. 카드를 "간직하고 싶다"는 감정이 생기는가?

## 프라이버시

닉네임·관심사만 수집합니다. App Clip은 계정 없이 동작합니다. 맞댄 사람 외에는 누구도 내 카드를 볼 수 없습니다. 계정 삭제는 앱 안에서 즉시 가능합니다.
