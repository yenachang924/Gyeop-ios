Process

문서가 단일 진실 원천. 결정은 번호로 쌓인다

docs → CLAUDE.md → 코드기준 변경은 반드시 문서 먼저. 에이전트가 바뀌어도 결정의 근거와 이력이 유실되지 않는다.
결정 번호 체계 R · U · F라운드마다 번호를 붙여 기각 이력까지 남긴다. "왜 이 색인가"에 항상 문서로 답할 수 있다.
취향 결정은 소유자에게에이전트는 2~3안 + 기본값을 제시하고, 선택은 소유자가 한다. 시각 제안은 HTML 리뷰 팩으로.

Key Decisions

기각과 재결정이 남긴 네 가지

R1 → U1 재결정

액센트 · 올리브를 뒤집고 POSTECH Red

Figma 라운드는 올리브(#66783A)를 골랐지만, 소유자 재결정으로 POSTECH Red(#A61955/#E0517F 동적)로 교체. 빨강은 "겹 성립" 순간과 프라이머리 CTA에만 · 한 화면 3곳 이상이면 실패로 간주하는 희소성 원칙.

R7 + U2

"겹!" · 0.5초의 브랜드

두 카드의 대표색 원이 위아래에서 다가와 액체처럼 융합(goo 메타볼). 좌우 배치는 "내 카드=왼쪽"이 대등하지 않아 기각. 성립 순간 더블탭 햅틱(예비 탭 → 도장 탭)이 손에 닿는다.

F17 재설계

성향 입력 · 격자를 버리고 2축 유동

2×2 4택1은 "딱딱하다"로 기각. 건강 앱 마음챙김(심리 상태)을 레퍼런스로 슬라이더 2축이 카드 색에 연속 기여 · 4분면 시드 색의 이중선형 보간. 저장값은 양자화되어 "같은 입력=같은 카드" 결정성은 유지.

F21 절제

카드 색 · 무지개를 7색으로

25개 제어점이 제각각이던 색은 실기기에서 무지개 노이즈였다. 7색 유사색 팔레트로 절제하고 성향이 색의 방향을 정하는 공식 규칙을 문서화 · 색을 보면 상대의 결이 읽힌다 (인앱 "카드 색 읽는 법").
